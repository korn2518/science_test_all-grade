# 설치 매뉴얼

NEON 형성평가 시스템 · 2022 개정 교육과정 중학교 과학

전체 40분 정도 걸리고, **한 번만** 하면 됩니다.

---

## 먼저 알아두기 — 언어가 바뀌나요?

**아니요. 그대로 Google Apps Script(자바스크립트)입니다.**

바뀐 것은 **어느 파일이 어디에 있느냐**뿐입니다.

| | v1 (이전) | v2 (지금) |
|---|---|---|
| 학생 응시 화면 | Apps Script가 HTML을 만들어 전송 | **GitHub Pages**에 정적 파일로 올려 둠 |
| 교사 출제실 | Apps Script | Apps Script (그대로) |
| 데이터 처리 | Apps Script | Apps Script (그대로) |
| 저장소 | 구글 스프레드시트 | 구글 스프레드시트 (그대로) |

Apps Script에 넣을 파일은 오히려 **6개 → 3개로 줄었습니다.**
(`Code.gs`, `Standards.gs`, `Teacher.html`)

---

## 1단계 — GitHub에 올리기 (10분)

GitHub 계정이 없으면 https://github.com/signup 에서 무료로 만듭니다.

1. 오른쪽 위 **+ → New repository**
2. Repository name: `science-quiz` (원하는 이름 아무거나, 영문 소문자 권장)
3. **Public** 선택 ← Pages를 쓰려면 공개여야 합니다 (무료 계정 기준)
4. **Create repository**
5. 나온 화면에서 **uploading an existing file** 클릭
6. 압축을 푼 폴더 안의 **파일과 폴더를 전부** 드래그해서 올립니다
   - `index.html`, `dashboard.html`, `config.js`, `README.md`, `LICENSE`, `404.html`, `.nojekyll`
   - `assets/` 폴더, `apps-script/` 폴더, `docs/` 폴더
7. 아래 **Commit changes** 클릭

### GitHub Pages 켜기

1. 저장소 상단 **Settings** → 왼쪽 메뉴 **Pages**
2. Source: **Deploy from a branch**
3. Branch: **main** / 폴더: **/ (root)** → **Save**
4. 1~2분 뒤 새로고침하면 주소가 나옵니다

```
https://내아이디.github.io/science-quiz/
```

**이 주소를 메모해 두세요.** (끝의 `/` 포함)

> 아직 열면 "평가 주소가 올바르지 않습니다"라고 나오는 게 정상입니다. 아직 API를 연결하지 않았으니까요.

---

## 2단계 — 스프레드시트 + Apps Script (15분)

### ① 스프레드시트

구글 드라이브 → 새로 만들기 → **Google 스프레드시트**
이름: `두레자연중 과학 형성평가 데이터`

### ② Apps Script 열기

그 스프레드시트에서 **확장 프로그램 → Apps Script**
프로젝트 이름: `형성평가 API`

### ③ 파일 3개 붙여넣기

`apps-script/` 폴더 안의 파일을 그대로 옮깁니다.

| Apps Script에서 만들 파일 | 종류 | 내용 |
|---|---|---|
| `Code.gs` | 스크립트 (기본 파일에 덮어쓰기) | `apps-script/Code.gs` |
| `Standards.gs` | 스크립트 (**+** → 스크립트) | `apps-script/Standards.gs` |
| `Teacher` | **HTML** (**+** → HTML) | `apps-script/Teacher.html` |

> ⚠ HTML 파일 이름에 `.html`을 붙이지 마세요. **`Teacher`** 라고만 입력합니다.
> (Apps Script가 자동으로 붙입니다.)

### ④ 시트 초기화

상단 함수 선택창에서 **`setup`** 선택 → **▶ 실행**
권한 승인 창 → `고급` → `...(안전하지 않음)으로 이동` → **허용**
(본인이 만든 스크립트라 나오는 정상 경고입니다.)

### ⑤ 웹 앱 배포

1. 오른쪽 위 **배포 → 새 배포**
2. ⚙ 아이콘 → **웹 앱**
3. 설명: `v2`
4. **다음 사용자 인증 정보로 실행: 나**
5. **액세스 권한이 있는 사용자: 모든 사용자** ← 반드시 이 설정
6. **배포**
7. 나온 **웹 앱 URL**(`.../exec`로 끝남)을 복사

---

## 3단계 — 둘을 연결 (5분)

### ① config.js 수정

1. GitHub 저장소로 돌아가 **`config.js`** 클릭
2. 오른쪽 위 연필(✏️) 아이콘
3. 아래 줄의 따옴표 안을 **웹 앱 URL**로 교체

```js
window.API_URL = "https://script.google.com/macros/s/AKfyc.../exec";
```

4. 아래 **Commit changes** → 1분 뒤 반영

### ② 출제실 설정

브라우저에서 **웹 앱 URL을 그대로 엽니다** → 출제실이 뜹니다 → **설정** 탭

| 항목 | 넣을 값 |
|---|---|
| Gemini API 키 | https://aistudio.google.com/apikey 에서 발급 (무료) |
| 모델 | **모델 목록 불러오기** 눌러서 `gemini-flash-latest` 계열 선택 |
| GitHub Pages 주소 | `https://내아이디.github.io/science-quiz` (**끝에 / 없이**) |
| 교사 PIN | 대시보드 열 때 쓸 비밀번호 |

**전체 저장** → **🔌 연결 테스트** 를 눌러 `✅ API 정상 응답`이 나오면 끝입니다.

---

## 4단계 — 확인

1. 출제실 → 문항 생성 → 아무 주제나 넣고 **⚡ 10문항 생성** → **💾 저장하고 링크 발급**
2. 나온 링크가 `github.io`로 시작하는지 확인
3. 그 링크를 휴대폰으로 열어 직접 응시해 보기
4. 대시보드(`.../dashboard.html`)에서 PIN 넣고 결과 확인
5. 테스트 기록은 스프레드시트 `응답` 시트에서 그 행만 지우면 됩니다

## 나중에 코드를 고쳤을 때 — 재배포 방법

### 학생 화면·대시보드를 고쳤다면 (GitHub Pages)

GitHub에서 파일을 수정하고 **Commit** 만 하면 됩니다.
1~2분 뒤 자동 반영. 배포 작업이 따로 없습니다.

> 학생이 예전 화면을 본다면 **새로고침(Ctrl+Shift+R)** 하라고 안내하세요.

### Apps Script를 고쳤다면

**질문하신 대로, 새로 만들 필요 없이 기존 배포를 수정하면 됩니다.**

```
배포 → 배포 관리 → (기존 배포 옆) 연필 ✏️
      → 버전: "새 버전" 선택 → 설명 입력 → 배포
```

이렇게 하면 **웹 앱 URL이 그대로 유지**됩니다.
`config.js`도 다시 안 고쳐도 되고, 이미 나눠준 학생 링크도 계속 살아 있습니다.

> ❌ **배포 → 새 배포**를 누르면 **URL이 새로 생깁니다.** 그러면 `config.js`도 고쳐야 하고
> 예전 링크가 끊깁니다. 반드시 **배포 관리 → 수정**을 쓰세요.

## 자주 겪는 상황

| 상황 | 해결 |
|---|---|
| 학생 화면에 "config.js의 API_URL이 설정되지 않았습니다" | `config.js`에 `/exec` 주소를 넣고 커밋했는지 확인 |
| 학생이 "권한 없음" 화면을 봄 | 배포 설정 → **액세스: 모든 사용자** 확인 |
| 링크가 `script.google.com`으로 나옴 | 출제실 설정에 **GitHub Pages 주소**를 안 넣은 상태. 넣고 저장한 뒤 다시 발급 |
| 대시보드 PIN 오류 | 출제실 설정에서 PIN을 저장했는지 확인 |
| Gemini 호출 실패 | 설정 → **모델 목록 불러오기** → 목록에 있는 이름으로 변경 |
| 문항을 고쳤는데 학생 화면이 그대로 | 설정 → **🧹 캐시 비우기** |
| 단답형이 맞는데 오답 처리됨 | `문제은행` 시트 → 문항JSON → 해당 문항 `accept` 배열에 표기 추가 → 캐시 비우기 |
| 학생 재응시가 필요함 | `응답` 시트에서 해당 행 삭제 |
| 응시를 막고 싶음 | 문제은행 탭에서 상태 칩(`공개`) 클릭 → `마감` |

## 보안 참고

- Gemini API 키는 **Apps Script 스크립트 속성에만** 저장되고 GitHub에 올라가지 않습니다.
- 학생 페이지에는 **정답이 전송되지 않습니다.** 채점은 서버에서만 합니다.
- 대시보드는 교사 PIN이 있어야 열립니다.
- 저장소가 Public이어도 노출되는 건 화면 코드뿐이며, 학생 데이터는 선생님 구글 계정 안에만 있습니다.

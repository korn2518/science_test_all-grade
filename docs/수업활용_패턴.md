# 수업 활용 패턴 8가지

### 패턴 A — 출구 티켓 (Exit Ticket) · 기본형
수업 마지막 7분. 제한시간 5분. 목표는 점수가 아니라 **"오늘 것이 남았는가"** 확인.
→ 대시보드에서 평균 70% 미만이면 다음 차시 도입을 복습으로 시작.

### 패턴 B — 사전 진단 (Entry Ticket)
새 단원 첫 차시 **시작 5분**에, 직전 학년 관련 성취기준으로 출제.
예) 중3 `9과19-01(운동 그래프)` 들어가기 전 중2 `9과05-03(알짜힘과 운동 상태)` 로 진단.
→ 결손 지점을 알고 수업을 시작할 수 있음.

### 패턴 C — 오답 3문항 재도전 (Two-Round)
1차 응시 → 대시보드에서 정답률 낮은 문항 3개 확인 → 5분 재설명
→ **같은 성취기준·같은 주제로 다시 생성**해 2차 배포.
1차/2차 점수 상승폭이 형성평가 기록으로 남습니다. 두 링크 모두 시트에 보존됩니다.

### 패턴 D — 짝 토론 후 재응답 (Peer Instruction)
1차 응시 → **정답은 공개하지 않고** 정답률 40~70% 문항만 화면에 띄움
→ 짝과 2분 토론 → 같은 평가 링크로 재응시(교사가 `응답` 시트에서 1차 행 삭제 또는 그대로 2행 누적)
→ 정답률 변화가 곧 토론 효과.

### 패턴 E — 난이도 계단 자기점검
생성된 문항은 **하 3 / 중 5 / 상 2**로 고정 배분됩니다.
학생에게 "하·중은 다 맞히기, 상 2문항은 도전"으로 안내하면 하위권이 포기하지 않습니다.
대시보드 문항별 표에 난이도가 함께 표시되므로 **"중 난이도인데 정답률 40%"** 인 문항이 진짜 결손 지점입니다.

### 패턴 F — 실험 직후 원리 확인
추가 요청 칸에 `오늘 한 ○○ 실험 상황을 2~3문항에 넣어주세요`라고 적으면
실험 맥락이 문항에 들어갑니다. 실험이 활동으로만 끝나는 것을 막는 장치.

### 패턴 G — 단원 마무리 누적 평가
단원의 성취기준을 하나씩 골라 여러 개 만들어 두고, 마무리 차시에 **2~3개 링크를 연속 배포**.
`대시보드 → 전체 누적`에서 학생별 추이를 확인할 수 있습니다.

### 패턴 H — 학기 말 성취수준 근거 자료
`응답` 시트에는 성취기준코드가 함께 저장됩니다.
피벗 테이블로 **학생 × 성취기준코드 → 평균 백분율**을 만들면,
생활기록부 교과 세부능력 특기사항이나 성취수준 판단의 **정량 근거**가 됩니다.

> 피벗 만들기: `응답` 시트 → 삽입 → 피벗 테이블
> 행 `이름`, 열 `성취기준코드`, 값 `백분율(평균)`

## 부록 — 성취기준 근거로 쓰기

`응답` 시트에는 제출마다 **성취기준코드**가 함께 저장됩니다.
피벗 테이블을 만들면 학생별·성취기준별 도달도가 바로 나옵니다.

> `응답` 시트 → 삽입 → 피벗 테이블
> 행 `이름` · 열 `성취기준코드` · 값 `백분율(평균)`

대시보드에서 **⬇ CSV** 를 눌러 내려받은 뒤 엑셀에서 정리해도 됩니다.

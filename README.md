# 과학 형성평가

2022 개정 교육과정 중학교 과학 · 두레자연중학교

수업 주제로 만든 형성평가 10문항을 학생이 태블릿에서 풀면
바로 채점되고 점수가 스프레드시트에 쌓입니다.

---

## 두 부분으로 되어 있습니다

| | 하는 일 | 어디에 |
|---|---|---|
| **Apps Script** | 문항 저장 · 채점 · 데이터 누적 · 관리실 | 구글 계정 안 |
| **이 저장소** | 태블릿에 설치되는 앱 껍데기 | GitHub Pages |

**Apps Script만으로도 작동합니다.** 이 저장소는 태블릿에서 *진짜 앱처럼*
(주소창 없는 전체화면 · 독립 아이콘) 쓰고 싶을 때만 있으면 됩니다.

---

## 설치

### 1단계 — Apps Script (필수)

1. 구글 스프레드시트 새로 만들기
2. **확장 프로그램 → Apps Script**
3. `apps-script/Code.gs` 내용을 전부 붙여넣고 저장
4. **배포 → 새 배포 → 웹 앱**
   - 실행: **나**
   - 액세스: **모든 사용자**
5. 나온 `/exec` 주소를 복사
6. 그 주소를 열어 관리자 비밀번호를 정하면 끝

### 2단계 — GitHub Pages (선택)

1. 이 파일들을 저장소에 업로드
2. **Settings → Pages → Branch: `main` / `/ (root)` → Save**
3. `config.js` 를 열어 한 줄 수정

```js
window.APP_URL = "https://script.google.com/macros/s/AKfyc.../exec";
```

4. 커밋하면 1~2분 뒤 반영

### 3단계 — 태블릿에 설치

GitHub Pages 주소를 학생 태블릿에서 열고

- **아이패드(Safari)** — 공유 버튼 → 홈 화면에 추가
- **안드로이드(Chrome)** — ⋮ → 앱 설치 (또는 홈 화면에 추가)

아이콘을 누르면 **그때 열려 있는 평가**로 바로 들어갑니다.

## 수업에서

1. AI에게 문항을 만들어 달라고 합니다 (`제미나이_프롬프트.txt` 사용)
2. 받은 코드를 관리실에 붙여넣고 **등록**
3. 학생은 아이콘을 누르면 끝
4. 수업 후 관리실 **[보기]** 에서 평균 · 문항별 정답률 확인
5. 끝나면 상태를 **마감** 으로

## 파일

```
├── index.html      앱 껍데기 (Apps Script 화면을 감쌉니다)
├── config.js       ⚙ 여기 한 줄만 수정
├── manifest.json   앱 이름 · 아이콘 · 전체화면 설정
├── sw.js           아이콘 눌렀을 때 즉시 뜨게 하는 캐시
├── icons/
├── apps-script/
│   └── Code.gs     Apps Script에 붙여넣을 파일 (백업 겸용)
├── 제미나이_프롬프트.txt
└── 예제_문항코드.txt
```

## 참고

- 학생 데이터는 선생님 구글 계정의 스프레드시트에만 저장됩니다. 이 저장소에는 아무것도 올라가지 않습니다.
- 저장소가 공개여도 노출되는 것은 화면 코드뿐입니다.
- Apps Script 코드를 고친 뒤에는 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**
- 이 저장소 파일을 고친 뒤에는 커밋만 하면 됩니다.
